# Infrastructure Lab

Personal homelab focused on developing practical skills in **networking, virtualization, Linux administration, security, automation, and infrastructure engineering**.

This repository documents the design, configuration, troubleshooting, and ongoing development of my home infrastructure.

### Services

### Automation

* Bash
* Python
* Git

## Lab Goals

The primary goals of this lab are to:

* Build practical networking and systems administration experience
* Learn and administer virtualized infrastructure
* Deploy and maintain Linux servers
* Develop secure remote-access solutions
* Practice network security and segmentation
* Learn infrastructure automation
* Develop Python and Bash scripting skills
* Learn containerization with Docker
* Develop Infrastructure-as-Code skills
* Document technical projects and troubleshooting processes
